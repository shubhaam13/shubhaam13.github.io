# Shubham Kumar — Portfolio

A responsive React portfolio for cloud and platform operations, DevOps and site reliability work. This site uses the existing Create React App setup and deploys to GitHub Pages.

## Run locally

1. Install Node.js (LTS).
2. Run `npm install` in this folder.
3. Run `npm start` and open http://localhost:3000.

Run `npm run build` to create the production site in `build/`.

## Features

- Responsive portfolio with an inline, one-time intro video and native playback controls.
- Resume-based professional summary, technical skills, experience and education.
- Accessible interactive terminal opened from the hero.
- LinkedIn, GitHub, Instagram and email links, plus email-based hiring and resume requests.
- tawk.to chat widget.

A phone number is not published on this site. Resume requests can be sent by email.

## Publish

`npm run deploy` builds the project and publishes the output to the `gh-pages` branch. The GitHub Pages site is https://shubhaam13.github.io/.
